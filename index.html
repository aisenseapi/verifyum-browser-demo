Independent verification

Do not take our word. Take none of it.

This page is not served by Verifyum. It fetches a proof, checks the signature, the anchor and the witness chain itself, and tells you what it found. You can also break the proof on purpose and watch it refuse.

Looking up the most recently anchored proof…

Any Solana node that allows a browser will do. Verifyum's own node is deliberately not offered here. Public nodes keep a shallow history, so the anchor step reports honestly when a proof is older than what the node serves.

    Your own file, if you have one

    A proof commits to exact bytes without revealing them. If you hold a file and the receipt written beside it, this checks that they belong together and that those bytes are the ones anchored. Both stay in the tab. Nothing is uploaded, and the nonce in your receipt is the secret half that Verifyum never had.

    Why this is hosted somewhere else

    A verifier served by the service it verifies proves very little. This page is on GitHub Pages. The code is in its repository, it is short enough to read, and it loads nothing from Verifyum: no library, no framework, no bundle. SHA-256 and Ed25519 come from the browser.

    The canonicalization and the Merkle rules here are written from the published protocol rather than copied from the Verifyum client, on purpose. Running the service's own code against the service's own answer would only show that the code agrees with itself.

    It still does not make this page neutral. We wrote it. What it removes is the host, and what it adds is that the verdict is computed where you can watch it, including the part where it says no.
